# RideNow - Ride-Hailing Web Platform Clone

Welcome to the **RideNow** repository! This project is a modern ride-hailing web platform interface modeled after transport applications like Ola, Uber, and Rapido, designed with a clean and responsive front-end layout.

🚗 About the Project
- **Developer:** Manish Yadav (**Manish Web Technologies**)
- **Location:** Bettiah, Bihar, India
- **Purpose:** Exploring transportation booking workflows, interactive UI design, and ride-hailing user experiences.

🛠️ Technologies Used
- HTML5 & CSS3
- JavaScript
- Responsive UI Design
